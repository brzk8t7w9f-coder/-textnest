TEXTNEST

What it does:
- Opens the iPhone/iPad Phone function for calls.
- Opens Messages for SMS/iMessage.
- Stores TextNest contacts and favorites locally.
- Includes four ringtone previews and remembers your selected tone.
- Can work offline after being installed/served as a web app.
- Shows Bluetooth support when available.

Important:
iOS does not let a normal web app independently place cellular calls or send SMS through Bluetooth.
Bluetooth call audio is controlled by iPhone/iPad Settings and the system Phone app.

To put TextNest on the Home Screen:
1. Put these files on a simple HTTPS web host, or open the hosted version if one is provided.
2. Open TextNest in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Tap Add.
